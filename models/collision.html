动量守恒；弹性碰撞动能守恒，非弹性碰撞有动能损失。v₁ > v₂ 时才会相撞。
01

动量与能量

动量守恒：m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′
能量守恒：
12m₁v₁² + 12m₂v₂² = 12m₁v₁′² + 12m₂v₂′² + ΔE
v₁、v₂ 为碰前速度，v₁′、v₂′ 为碰后速度；ΔE 为碰撞损失的动能。
02

弹性碰撞

ΔE = 0
v₁′ = (m₁ − m₂)v₁ + 2m₂v₂m₁ + m₂
v₂′ = (m₂ − m₁)v₂ + 2m₁v₁m₁ + m₂
弹性碰撞中动量与动能同时守恒，恢复系数 e = 1。
03

非弹性碰撞

ΔE ≠ 0；完全非弹性碰撞 ΔE 取最大值，碰后两球共同运动。
m₁v₁ + m₂v₂ = (m₁ + m₂)v共
12m₁v₁² + 12m₂v₂² = 12(m₁ + m₂)v共² + ΔEmax
完全非弹性碰撞后两球速度相同，动能损失达到最大值。
